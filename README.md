# Gecikme Mazereti Fabrikası ⚡

**Dikkat!** Bu depo, insanlığın en büyük sorununu çözmek için yaratılmıştır: **GECİKMEK.**

Artık "trafik vardı" demek sıkıcı. Bu fabrika, tamamen absürt, abartılı ve kimsenin inanmayacağı ama yine de deneyeceğiniz mazeretler üretir.

## Nasıl Çalışır?

```bash
python mazeret_ureteci.py
```

Ve boom! Karşınızda eşsiz bir mazeret.

## Özellikler

- %100 gerçekçi değil
- %200 abartılı
- Patronu ikna etmez ama güldürür
- Uzaylı istilası, kuantum kedisi, zaman paradoksu gibi ileri seviye mazeretler

## Uyarı

Bu kodu çalıştırırsanız işinize geç kalabilirsiniz. Sorumluluk kabul etmiyoruz.
